Detailed Description

Imports CMX 3600 edit decision lists into the shared timeline model.

Non-drop-frame files require the cmx3600.frame_rate import option with a value such as 24, 25, or 30000/1001. Drop-frame files default to 30000/1001 when the option is omitted.
